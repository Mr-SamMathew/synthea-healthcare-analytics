Clinical Encounter Dashboard

An interactive dashboard analyzing patient encounter volume, demographics, and healthcare costs.

What's Inside
1) KPI & Filters: Tracks Total Encounters with dynamic Year and Gender slicer.
2) Encounters Over Time: Monthly trend line highlighting seasonal volume spikes (peaking in March).
3) Patients per Encounter Class: Volume breakdown across Wellness, Ambulatory, Outpatient, Inpatient, Emergency, and Urgent Care.
4) Demographics: Patient distribution by Race (White, Black, Asian, Native, Other).
5) Healthcare Costs: Compares Total Claim Cost vs. Payer Coverage across each encounter class.

Quick Start
1. Clone this repository or download the dashboard file.
2. Open the file in Power BI.
3. Use the top-right Year and Gender dropdowns to filter the data.

Built With
1) BI Tool: Power BI
2) Data Source: provided in the data folder
